# Enhanced Rock Weathering (ERW) Pilot — India

## Project Overview

This project presents a market research, go-to-market, and financial planning case study for an Enhanced Rock Weathering (ERW) pilot in India.

The proposed deployment plan explores the logistics, site suitability, operational requirements, measurement and verification framework, and financial considerations involved in deploying basalt rock powder on agricultural land in Madhya Pradesh.

## Project Objectives

- Evaluate potential Indian regions for ERW deployment.
- Develop a site-selection framework using soil conditions, basalt availability, rainfall, transport feasibility, and farmer aggregation.
- Design an operational roadmap for a proposed 10,000 MT basalt powder deployment.
- Estimate transportation, procurement, and deployment costs.
- Outline soil and rock sampling, monitoring, reporting, and verification (MRV) requirements.
- Develop a five-year financial projection and cash-flow model.

## Project Scope

- **Proposed deployment:** 10,000 metric tonnes of basalt rock powder
- **Target geography:** Madhya Pradesh, India
- **Primary focus area:** Khandwa and selected districts in western and central Madhya Pradesh
- **Indicative application area:** 500 hectares
- **Planning horizon:** Six-month pilot implementation roadmap
- **Financial model:** Five-year projection
